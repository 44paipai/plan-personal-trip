# plan-personal-trip

为用户研究新目的地、从候选景点中做取舍，并按个人体力、节奏、住宿与预算偏好生成可执行行程；也可参考既有旅行攻略制作带时间、内容和预算的 Excel。用于“想去某地但不知道玩什么/几天/预算”“按我以往风格规划旅行”“把行程做成 Excel”等请求，不用于单纯查询一个景点事实。

## 安装

```bash
npx -y skills add 44paipai/plan-personal-trip -g --all
```

## 使用

安装后，可以这样开始：

> 使用 $plan-personal-trip 根据我的偏好研究目的地、筛选路线，并生成带时间、内容和预算的行程。

## 运行依赖

- 支持 Agent Skills 的客户端

## 内容

本仓库只发布运行这个 Skill 所需的文件。本地评测样本、预期答案和运行记录不包含在公开包中。
